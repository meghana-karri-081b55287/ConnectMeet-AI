# ConnectMeet AI

## Overview

ConnectMeet AI is an intelligent video conferencing and meeting collaboration platform inspired by Zoom, Google Meet, and Microsoft Teams.

The platform integrates Artificial Intelligence capabilities to automate meeting documentation, generate summaries, extract action items, and provide intelligent meeting insights.

---

## Features

### Core Features

- User Authentication & Management
- Video & Audio Conferencing
- Meeting Scheduling
- Meeting Room Management
- Screen Sharing
- Chat & Messaging
- File Sharing
- Meeting History
- Admin Dashboard
- Analytics Dashboard

### AI Features

- Speech-to-Text Transcription
- Meeting Summarization
- Action Item Extraction
- Speaker Identification
- Meeting Insights
- Smart Follow-Up Recommendations
- Natural Language Meeting Search
